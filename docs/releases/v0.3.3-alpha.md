# v0.3.3 Alpha - Productized Operations And Read-Only Operator Foundation

Status: draft release note. Phase 28 D12 QA/PM close and D13 immutable image
publication are still pending.

## Summary

Seaweed Block v0.3.3 alpha is the packaging target for the Phase 28
productized operations work.

The release boundary is:

```text
Helm install
-> first PVC and multi-volume smoke
-> product-owned ManagedVolume state
-> read-only report/dashboard/support bundle
-> operator-snapshot.json for future Kubernetes operator status
-> cleanup verifier
-> QA/PM close
```

This is not a production operator release. The operator foundation is
status/read-only only.

## User-Visible Additions

- Stable ManagedVolume operations vocabulary shared by report, dashboard,
  support bundle, explain output, and future operator status.
- Kubernetes-native CRD / Condition / Event contract for future status-only
  operator work.
- New read-only operator foundation artifact:

```text
operator-snapshot.json
```

- `sw-block ops report` writes the operator snapshot beside:
  - `index.html`
  - `cluster-evidence.json`
  - `timeline.jsonl`
  - `summary.txt`
- `sw-block ops dashboard` serves:
  - `/operator-snapshot.json`
- Cleanup verifier now covers iSCSI sessions, iSCSI node DB, Kubernetes
  resources, product processes, dm-multipath maps, and `dmsetup` residue.
- Phase 27 mounted/interleaved multi-volume failover gates have Phase 28 N=5
  flake matrix evidence with `flake_rate_percent=0`.

## Current Claim

After D12 passes, Seaweed Block v0.3.3 alpha may claim:

- Helm remains the supported alpha Kubernetes install path.
- The operations surface has one shared ManagedVolume vocabulary.
- `sw-block ops report` and dashboard expose read-only status artifacts,
  including an operator-oriented snapshot.
- Future operator status has a documented CRD/Condition/Event contract.
- Cleanup evidence includes multipath and device-mapper residue checks.

Until D12 passes, this release note is a draft and these are target claims.

## Explicit Non-Claims

- Not production-ready.
- No production Kubernetes operator.
- No installed CRDs or controller-manager lifecycle in this release note unless
  separately gated later.
- No mutating operator actions.
- No promote, repair, rebuild, failback, delete, backup, restore, or cleanup
  mutation through UI/API/operator.
- No broad upgrade safety beyond existing gated smoke paths.
- No broad platform compatibility matrix.
- No performance, RTO, RPO, or SLO claim.
- No new NVMe ANA, backup/restore, or returned-replica rebuild capability.
